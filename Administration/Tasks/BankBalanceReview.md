# Bank Balance Review and Adjustment SOP

Use this SOP when an admin needs to review a player's ATM/bank balance or correct a bank balance after a verified issue.

## When To Use

Use this for:

- Player reports of missing ATM money
- Player reports of duplicate or incorrect transfers
- Account reset cleanup
- Verified admin correction after a bug or rollback
- Reviewing suspicious balances or transfer activity

Do not use this as a shortcut for gifts, compensation without evidence, or informal staff favors.

## Required Access

Balance checks use `Remote-NPC` RC commands.

Changing a bank balance requires either:

- Staff level 4 or higher
- `staff_right_changebank` in `ServerOptions`

## Source Commands

Check a bank balance:

```text
/npc checkbank <account>
```

Alias:

```text
/npc bankcheck <account>
```

Start a balance change:

```text
/npc changebank <account> <new_amount>
```

Alias:

```text
/npc bankchange <account> <new_amount>
```

Confirm the pending change:

```text
/npc bankconfirm <code>
```

The confirmation code is generated by `Remote-NPC` after `/npc changebank`.

## Important Account Rule

Use the real account name, not the community name. Existing staff documentation also notes that account capitalization matters for this workflow.

If the player only gives a community name, resolve the real account first before using bank commands.

## Before You Adjust

Before changing a balance, collect evidence:

- Current bank balance from `/npc checkbank <account>`
- Player's `bankatm` logs
- `atmlog.txt`
- `atmlog_bigxfers.txt` for transfers over `$750,000`
- Trade, item, market, or gPhone logs if the issue involves another system
- Screenshots or player statements as supporting evidence only

The authoritative source is server-side logs and the bank table, not a screenshot of a GUI.

## Review Procedure

1. Confirm the real account name.
2. Run `/npc checkbank <account>`.
3. Review the player's bank activity logs.
4. Identify the exact transaction or system event that caused the issue.
5. Decide whether the balance should remain unchanged, be restored, or be reduced.
6. Document the reason before making any change.

## Adjustment Procedure

1. Run `/npc checkbank <account>` and record the current balance.
2. Calculate the final intended balance. The command sets the total balance, not a delta.
3. Run `/npc changebank <account> <new_amount>`.
4. Read the confirmation message carefully.
5. If the account and amount are correct, run `/npc bankconfirm <code>`.
6. Run `/npc checkbank <account>` again to verify the new balance.
7. Record the reason and evidence in the relevant staff notes or ticket.

## What The Script Logs

When confirmed, `Remote-NPC`:

- Reads the old balance through `DB_Bank.getBalance()`
- Sets the new balance through `DB_Bank.setBalance()`
- Echoes the change to RC
- Saves a line to `bankbalance_change.txt`
- Updates `data/ice/bankchangeWatch.txt` if the staff member has `staff_right_changebank`

`bank_functions.setBalance()` also logs a `bankatm` account log entry and updates the bank table transaction count and `lastuse`.

## Safety Rules

- Never adjust a balance without first checking the current balance.
- Never treat `/npc changebank` as an add/subtract command. It sets the full new balance.
- Never confirm a change if the generated message shows the wrong account or amount.
- Never use community names in the command.
- Never change a bank balance only from a screenshot.
- Never reset a player's account without also checking whether their bank account needs to be reset.

## Common Outcomes

No adjustment:

- Use when logs show the money was spent, transferred, withdrawn, or lost through valid gameplay.

Restore balance:

- Use when logs show a verified server issue, failed delivery, rollback, or staff-approved correction.

Reduce balance:

- Use when duplicated funds, exploit funds, or incorrect manual credit is verified.

Escalate:

- Use when the logs are incomplete, the amount is unusually large, the case involves USD/scam behavior, or the player is already under investigation.
